## 🎨 Overview

**vibe-Code** represents a cohesive laboratory of frontend engineering, modern design systems, and interactive experiences. Each project in this collection is a fully-realized web application tailored to specific industry aesthetics — from heritage retail and boutique hospitality to editorial beauty salons and artisanal ateliers.

To view the live portfolio hub, open [`index.html`](index.html) or launch any project's dedicated workspace.

## 🛠️ Technologies & Architecture

Across all projects, standard production-grade tooling is implemented:

- **Framework**: [React 18+](https://react.dev/)
- **Language**: [TypeScript](https://www.typescriptlang.org/) for strict type safety
- **Styling**: [TailwindCSS](https://tailwindcss.com/) & custom CSS variable tokens
- **Build Tool**: [Vite](https://vitejs.dev/) for lightning-fast HMR and bundle optimization
- **Icons**: Lucide Icons & Custom SVG assets
- **Responsiveness**: Mobile-first fluid grid systems

## 🚀 Getting Started

To run any individual project locally:

```bash
# 1. Clone the repository
git clone https://github.com/kumail-ahmad/vibe-Code.git
cd vibe-Code

# 2. Navigate to your target project folder
cd 001_Browns_Sporting_Goods/website
# OR
cd "005_Aiko Hair Salon"

# 3. Install dependencies and launch dev server
npm install
npm run dev
```
