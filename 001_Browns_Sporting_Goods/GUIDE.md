# Brown's Sporting Goods // Project Architecture

## Overview
A modern e-commerce and heritage storefront tailored for an outdoor sporting goods retailer.

### Tech Stack
- **Framework**: React 18 with TypeScript
- **Styling**: TailwindCSS
- **Bundler**: Vite

### Running Locally
```bash
cd 001_Browns_Sporting_Goods/website
npm install
npm run dev
```
